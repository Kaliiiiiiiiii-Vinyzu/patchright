# Security Policy

How to report a security problem in this repository privately, and what this policy covers.

## Reporting a vulnerability

Please do **not** report security vulnerabilities through public GitHub issues, discussions or pull requests.

Instead, report them privately through GitHub's
[private vulnerability reporting](https://github.com/Kaliiiiiiiiii-Vinyzu/patchright/security/advisories/new)
("Report a vulnerability" on the repository's Security tab).

Please include:

- a description of the issue and its impact,
- the affected files, workflows or package versions,
- steps to reproduce or a proof of concept, if you have one.

Please give us a chance to fix the issue before disclosing it publicly.

## Scope

This covers the code in this repository, its GitHub Actions release pipeline, and the packages it publishes
(`patchright-core` and `patchright` on npm). Issues in upstream Playwright should be reported to
[Microsoft](https://github.com/microsoft/playwright/security/policy).
